> 本文件是**执行级**文档：先给"要做哪些界面/交互"的全量功能列表，再给分批重写计划与验收门槛。
> 上位依据：[前端重写计划.md](./前端重写计划.md)（阶段策略）、[SWF前端逻辑还原/索引.md](./SWF前端逻辑还原/索引.md)（11 域交互与页面逻辑还原）、[SWF前端逻辑还原/12-美术资源归属总表.md](./SWF前端逻辑还原/12-美术资源归属总表.md)（179 资源族 × AS 出处 × 前端文件数 × 重写版接入状态）、[复刻对照表.md](./复刻对照表.md)（后端模块状态）、[前端美术资源清单.md](./前端美术资源清单.md)。

## 一、目标与两条硬要求

**目标**：把原版 Flash 客户端的界面与交互**逐屏复原**到 Vue 3 前端，视觉与交互 1:1。

**硬要求（不可偏离）**
1. **交互逻辑以 AS 为准**：每个控件的事件 → 命令 ID/参数 → 后端函数 → 回包字段 → UI 变化，均以 [SWF前端逻辑还原/](./SWF前端逻辑还原/索引.md) 各域文档的第 3 节为准；**不修原版怪癖**（含"成功提示走 400"、`checkLottoryTime` 恒抛等）。
2. **美术资源以原版为准**：所有图片走 `/images/...` 或 `src/assets/img.ts` 构造器，**不自绘替代**；资源族→界面的对应关系以 [12-美术资源归属总表](./SWF前端逻辑还原/12-美术资源归属总表.md) 为准。
