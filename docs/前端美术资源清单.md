## 七、核对工具（已升级）

`frontend/scripts/check-assets.mjs`（`npm run check:assets`）由"仅字面量核对"升级为三段：

1. **字面量核对**：`src/**` 中 `/images/...` 字面量（含 CSS `url()`）与实际文件比对，缺失即 **退出码 1**（可用于 CI）
2. **动态规则核对**：自动从源码 `img(\`...\`)` 模板提取命名规则（`${...}` → 通配），输出每条规则命中数与来源文件
3. **未使用清单**：输出"未被任何字面量或规则命中"的文件统计与明细；`--list` 输出完整清单

```
npm run check:assets           # 三段报告（明细前 120 条）
node scripts/check-assets.mjs --list   # 完整未使用清单
```

当前结果：**字面量 61 条 / 缺失 0 / 退出码 0**；未使用 3849（57.7%）。
