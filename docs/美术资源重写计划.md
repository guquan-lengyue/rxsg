## 阶段 0 · 资源接入骨架

- [ ] `images\` **整体拷入** `frontend/public/images\`（保留目录结构与原始文件名字节），确认 `frontend/public` 未被 `.gitignore` 排除
- [ ] `git check-ignore frontend/public` 检查；必要时放行
- [ ] 新建 `frontend/src/assets/img.ts`：
  - `const IMAGES_BASE = '/images'`
  - `img(rel)` → `${IMAGES_BASE}/${rel}`，防重复 `/`
  - `preloadPaths([])`：预取一组 URL
  - 各语义构造器：`heroFace(sex,face)`、`soldierIcon(sid)`、`soldierBig(sid)`、`buildingIntro(bid)`、`general(rel)`
- [ ] Vite 默认 `publicDir='public'`，无需配置；`vite build` 会把 `public/` 拷入 `dist/`
- [ ] 验证：dev 下 `curl /images/hero/hero_boy_1.jpg` → 200；`vite build` 产物含 `dist/images/`

> ⚠️ 提交体量大：`images/` 成百上千张、含大图，首次提交体积可观，属预期。
