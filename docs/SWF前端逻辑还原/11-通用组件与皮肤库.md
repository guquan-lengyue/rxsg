## 2. 界面结构与字段（组件结构 + 皮肤装配机制）

### 2.1 三层皮肤装配

原版所有控件外观由「**CSS 样式类 → 皮肤符号类 → 位图/矢量**」装配，路径三段：

1. **主 CSS 主题**：`BloodWar.as` 中 ~185 个 `StyleManager.setStyleDeclaration("<Sel>",style,false)`（`BloodWar.as:1802`–`4751`），每个设 `upSkin/overSkin/downSkin/borderSkin/…` = 一个 `_embed_css_*` 资源类。
2. **资源类**：`BloodWar/scripts/BloodWar__embed_css_*.as`（`[Embed(source="/_assets/assets.swf", symbol="symbolN")]`，主 SWF 的图片被打包进 `assets.swf` 按 symbol 号引用）与 `common2/scripts/common2__embed_css_*.as`（`[Embed(source="/_assets/<ID>_<类名>.png")]`）。
3. **位图/矢量**：`common2/images/<ID>_<类名>.png`、`swf/*/sprites/DefineSprite_<ID>_<名>/*.png`、`swf/*/shapes/<ID>.svg`。

## 3. 交互逻辑（核心）

本域组件交互均由 Flex 框架驱动，无独立 `sendDialogCommand`。核心链路的**皮肤绑定**如下：

| 控件 | AS 装配位置 | 命令/参数 | 后端函数 | 回包字段 | UI 变化 |
|---|---|---|---|---|---|

| `AlertPanel`（跑马灯） | `BloodWar.as:2429-2440`；类 `utils/AlertPanel.as:32` | — | — | — | 735×50 Canvas，`fadeIn`/`fadeOut`（`Fade` 效果），`textObj` 30px 居中 |
| `ToolTip` | `BloodWar.as:2158-2179` | — | — | — | `borderSkin=board_tip`，黑底 0.8 透明，白字 12px |

| 数字输入 | `BloodWar.as:3543`；`Ground/NumberSteper.as:31` | — | — | — | `numericstepper_*` 皮肤 |

**Tip 类使用方式**（框架 `mx.controls.ToolTip` + `ToolTipManager`，见 `bloodcommon.swc/.../mx/managers/ToolTipManager.as`）：业务类实现 `IToolTip` 后由 `ToolTipManager` 按 `toolTip` 字符串反射实例化（机制 B 具名链接类）。

### 3.1 资源加载三条机制（本域全部命中）

- **机制 A（`[Embed]`）**：`common2__embed_css_*.as` 内 `[Embed(source="/_assets/<ID>_<类名>.png")]`（例 `common2/scripts/common2__embed_css_images_button_gold_png_686593631.as:5` → `/_assets/187_common2__embed_css_images_button_gold_png_686593631.png`）。
- **机制 B（具名链接类）**：UIParts/skin 的 `DefineSprite_<ID>_<名>`（见 §5.2）经 `symbolClass/symbols.csv` 映射到 `<名>` 类；`SwfLoader.as:37-41` 用 `ApplicationDomain.currentDomain.getDefinition("round_1")` 取类。
- **机制 C（运行时 URL）**：`Global.getImagePathFunc()`（`BloodWar/scripts/Global.as:515`，内部 `ExternalInterface.call("getImagePath")`）拼 `images/<族>/<名>.png|jpg`，见 §5.5。

## 4. 状态机与流程

1. **样式加载**：主 SWF 启动 → `StyleManager.loadStyleDeclarations("common2.swf"…)`（`StyleManagerImpl.as:270/348`）→ 模块 `common2`（`common2.as:10 extends ModuleBase implements IStyleModule`）注入 ~185 个 `CSSStyleDeclaration`；同时 `BloodWar.as` 自带的 ~185 个样式覆盖默认。
2. **控件渲染**：控件实例化 → `StyleManager.getStyleDeclaration("<Sel>")` → 取皮肤类 → 实例化 `BitmapAsset`/`SpriteAsset`。
3. **swf 动画装载**：`SwfLoader.loadSwf("swf/battleRound.swf")`（`Loader/SwfLoader.as:43`）→ `LoaderContext.applicationDomain = currentDomain`（同域共享，故可 `getDefinition("round_N")`）→ `Event.COMPLETE` → `getSwf()` 循环取 `round_1..round_6`（`SwfLoader.as:22-35`）。
4. **战斗特效预热**：`BloodWar.as:8050` `loadSWF("swf/heroBattleEffect.swf",effectComplete)` → 回调内 `HeroBattlePanel.Baoji=getEffectByName("Baoji")` …（`BloodWar.as:7339-7346`）→ 战斗时 `addChild` 后 `gotoAndPlay(1)`（`HeroBattlePanel.as:1338-1411`）。
5. **异常分支**：`Global.getImagePathFunc()` 返回 null 时置 `""`（`Global.as:517-522`）；`swf/pass/*.swf` 验证码走 `Command.as:505`（不在本域 15 包内）。

## 8. 原版怪癖与注意事项

1. **两套皮肤并存且同名重复**：`BloodWar.as` 与 `common2.as` 各自注入 `Button`/`CheckBox`/… 样式，主 CSS 会覆盖 `common2` 默认（`getStyleDeclaration` 先到先得，`BloodWar.as:1958` 在运行期覆盖）。
2. **同一图片两种内嵌路径**：主 SWF 用 `/_assets/assets.swf symbol=N`（如 `BloodWar__embed_css_images_board_popup_png_2133715165.as:5` = `symbol="symbol129"`），`common2` 用 `/_assets/<ID>_<类名>.png`；重写版须区分两套 ID 来源。
3. **`symbols.csv` 有重复/非唯一字符ID**：`common2/symbols.csv` 同 ID 多行（见 §5.3 怪癖），遍历时以「类名」而非 ID 为键。
4. **`SwfLoader` 同域加载**：`LoaderContext.applicationDomain = currentDomain`（`SwfLoader.as:47`）使被加载 SWF 的符号类在主域可见；`hasLoaded` 静态标志（`SwfLoader.as:15`）防重复装载。
5. **Flex 自动生成类**：`*_inlineComponent*.as`（Rank/Stat/Store 等）、`*WatcherSetupUtil`、`_<Component>Style.as` 均为编译器产物，非手写逻辑，重写版可忽略。
6. **`skin.swf` 的装载点未见**：其符号为框架 `mx.skins.halo.*` 身份，但脚本中未见 `skin.swf` 字面量（仅 `_ButtonStyle.as` 等引用 `mx.skins.halo.ButtonSkin`）——**待确认**它是编译期主题还是独立资源。
7. **`bloodwar*.swf`/`button_up.swf` 为 Flash Screen 模板**：含 `mx.screens.Form/Slide/Screen` + `幻灯片1/演示文稿`，疑为作者文档/组件，未被游戏脚本引用（**待确认**）。
8. **`unActiveHero.swf` 帧内容为空边框**（`frames/*.png`、`sprites/DefineSprite_2/1.png` 均为空占位），疑似废弃/占位资源（**待确认**）。
