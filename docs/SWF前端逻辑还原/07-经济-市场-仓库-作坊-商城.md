## 4. 状态机与流程

**市场**：点建筑 → `getBuildingInfo`（`BuildingFunc.php:282` 对 bid13 追加 `doGetCityTrade`）→ `MarketDialog.onBuildingInfo(param2==0)` → `MarketPanel.onLoadInfo(param1[2])` 建表；子弹窗各自请求（`getUserSellData`/`getUserBuyList`/`getAutoTrans`）；任一操作成功后回包 `getMarketInfo`（=重发 `getBuildingInfo`）刷新；`onTimer` 每 tick 倒计时，归零触发重载。
**仓库**：点建筑 → `doGetStoreInfo`（`BuildingFunc.php:297`）→ `StoreDialog.onBuildingInfo(0)` → `initData+onData` 建表并显示容量/闲置；改比例 → `modifyStoreRate` 抛成功文案；打包 → `payToPack` 回 `[0,0]` 并提示。
**商城**：打开 → `getShopInfo` → 本地 4×N 分类 → 点击商品 → `BuyGoodsDialog` → `buyGoods`/`buyGoodsUsingCopper` → 更新余额并提示；购买前使用走独立 `buybeforeuse` 全局通道。
**异常分支**：所有后端校验均 `throw new Exception(文案)` → `Command.php:158` 打包 `[0,msg]` → 客户端 `Global.app.alert(msg)`；前端还有本地 Alert（数量/上限/未入盟/冷却等，见各节）。
