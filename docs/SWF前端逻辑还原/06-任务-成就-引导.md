## 4. 状态机与流程

### 4.1 任务面板
1. **打开** `showTaskDialog` → `getTaskGroupList()`（发 `task/getTaskTypeGroupList[mTaskType]`）→ 置 `mLastTaskType=0`。
2. **回包** `onGetTaskGroupList`：填充 `mTaskGroups`（`count=0` 的组不显示绿色数字）；`mTaskType∈{2,4}` 时 `mCurrentTaskTypeName = 名 + _29 + 组数 + _30`（`TaskDialog.as:607-610`）；默认选中 `mLastSelectGroupID`（记忆上次）；空组→右栏提示 i18n `_31`（type7 为 `_31_5`）；`dropBtn.enabled=checkDropEnable()`。
3. **选组** `onClickTaskGroup` → `showTaskGroup`（`showTaskGroupDetail` 显示组描述）+ `getTaskList(groupid)`。
4. **回包** `onGetTaskList`：清空并填 `mTasks`；记忆 `mLastTaskIdx`；空列表→提示 i18n `_33`；默认选中展示首条详情 + `getTaskDetail(tid)`。
5. **选任务** `onClickTask` → `showTaskDetail`：`type==0`（分组占位）→ `showTaskGroupDetail`；否则 `getTaskDetail`。
6. **领奖** `onClickGetReward`（校验/分流，见 3.1）→ `getReward` → `onGetReward`：返回数组首元素 `==1` 表示成功 → `Global.app.alert(Task_TaskDialogSrc_55)`；否则 `Alert(param1.shift())`（后端异常文本）；随后清空内容并重刷组列表。
7. **放弃** 确认框（`Alert.show(text,"",3,this,handler)`，`3`=YES/NO）→ 发 `dropTask`/`dropSysTask`。
8. **关闭** `onClose` → `visible=false`。

### 4.2 成就面板
1. **打开总览**：发 `achivement/getOverviewStat[uid]` → `resetOverviewStatData`（最近 2 条 + 9 进度条 + 总进度）+ `showOverivewStat`（`profileCanvas` visible、`mAchieveGroupList.selectedIndex=0`）。
2. **切分组**：`mAchieveGroupList` itemClick → 非 0 行 → `reloadAchivementsByGroup`（发 `getAchivementsByGroup`）→ `resetAchivementsByGroupData`（`mPageCount=(count+4)/5`），`pageLabel` 显示 `page/pageCount`，`showAchieveGroup`。
3. **切筛选/翻页**：重复第 2 步。
4. **看详情**：点 `AchieveItem` → 发 `getAchivementDetail` → `resetAchivementDetailData` → `showAchieveGuide`（`achieveGuideCanvas`），`buttonReturn` 出现；返回 → `onReturn` 切回 `mCurrentCanvas`。
5. **排行榜**：`showAchivementDialog` → `reloadList`（`getPageRank[0, rankType]`）→ `onCommand` 填表；翻页/排序/三个查询命令复用同一渲染分支。

### 4.3 引导
- **触发**（三选一）：新角色登录（`mJustCreateRole=true`）→ 弹 `JackarooDialog` 取组 1；建筑完工事件（`tiggerGuideByBuildingStates`）；数值事件（`tiggerGuideTip`，预留）。
- **展示** `showGuideTipNow`：若已有 `curGuideTip` 直接 return（同时只显示一条）；按 `content` 把 `“…”` 包成红色；`showpos` 决定气泡/箭头位置（空则居中 `300,200` 且藏箭头）；`distype==1` 时设消失区+挖空遮罩；`bLastGid` 控制显示「跳过」还是「完成」。
- **推进** `disEventHander` 命中消失区 → `completeGuide()`（本地移除当前 tip）→ `showNextGuide()`（找 `pregid==cur_gid` 的下一条）。
- **结束** 末条完成或跳过 → `mJustCreateRole=false`。

## 8. 原版怪癖与注意事项

1. **任务页签与类型编号错位**：`Button3` 对应 type3、`Button4` 对应 type2、`Button5` 对应 type5、`Button6` 对应 type7、`Button7` 对应 type6（`TaskDialog.as:1168-1277/1954-1968/908/1127/1685`）；**type==4（委托/悬赏）无页签**，只能从客栈入口打开，且 `switchPanel(4)` 在脚本中从未被页签调用。
2. **`checkDropEnable` 语义按类型反转**：`mTaskType==7` 返回 `!mTaskGroupSelected`（系统任务需先选中任务才可放弃），其余类型返回 `mTaskGroupSelected`（`TaskDialog.as:1132-1144`）。
