### 3.3 世界地图渲染体系
- **分块加载 `getBlockData`**（`WorldFunc.php:11-45`）：入参为 block 数组；`blockstart = block*100`，`blockend = blockstart+100`；每块返回 `[blockstart, group_concat((wid-blockstart),':',type,':',ownercid,':',state,':',level,':',province,':',jun)]`（`WorldFunc.php:24-25`）。响应为 `[ 块数组, 联盟标记数组(marks) ]`（`WorldFunc.php:36-38`），并额外 `file_put_contents` 落日志（`39-41`）。
- **block 划分推导**：`wid = cid2wid`（见 §3.4），故 `block = floor(wid/100) = floor(y/10)*100 + floor(x/10)`；`wid - blockstart = (y%10)*10 + (x%10)`。全图 100×100 → block ∈ [0,909]，每块 10×10 格。**重写版 `worldGrid.ts:102-121` 与此逐字一致**（`blockOf`/`blocksInView`）。
- **拼接串解析**：`split(',')` 后每项 `split(':')` 取 7 段（`wid偏移:type:ownercid:state:level:province:jun`）；**重写版 `api/world.ts:210-237 parseBlockConcat` 即此解析**。
- 视口常量（`WorldPanel.as`，值均在构造期声明，**语义因截断待确认**）：
  - `GRID_OFFSET_X=54`、`GRID_OFFSET_Y=27`（`486/488`）——等距瓦片半格步进。
  - `GRID_IMAGE_HEIGHT=75`（`910`）——地格贴图高。

### 3.4 坐标换算（★与后端逐字核对）
- AS：`Utils.cid2wid`（`Utils.as:371-376`）与 `Utils.wid2cid`（`Utils.as:283-286`）。
- 后端：`utils.php:663 cid2wid`、`utils.php:462 wid2cid`。

| 函数 | AS（`Utils.as`） | PHP（`utils.php`） | 结论 |
|---|---|---|---|
| `cid2wid(cid)` | `y=floor(cid/1000); x=cid%1000; floor(y/10)*10000 + floor(x/10)*100 + (y%10)*10 + (x%10)` | `$y=floor($cid/1000); $x=$cid%1000; floor($y/10)*10000 + floor($x/10)*100 + ($y%10)*10 + ($x%10)` | **完全一致** |
| `wid2cid(wid)` | `(floor(wid/10000)*10 + floor(wid%100/10))*1000 + floor(wid%10000/100)*10 + floor(wid%10)` | `$y=floor($wid/10000)*10 + floor(($wid%100)/10); $x=floor(($wid%10000)/100)*10 + floor($wid%10); $y*1000+$x` | **完全一致** |

- 地图坐标同构：`cid = y*1000 + x`（x=`cid%1000`，y=`floor(cid/1000)`），被 `WorldMapCityButton`（`WorldMapCityButton.as:112/170/263-264`）与 `BloodWar.as:5117` 直接使用。
- 服务端 SQL 中亦内联同式换算（`WorldFunc.php:829-833` `checkCanInvade`）。**重写版 `worldGrid.ts:79-89 cidToWid/widToCid` 亦逐字一致。**

## 4. 状态机与流程

1. **进入**：`gotoWorld()`（`BloodWar.as:8186`）→ `worldPanel.onShowPanel()`（截断）→ 以 `CENTER_GRID_X/Y=314/250`（或默认值）为中心，按 `LOADRANGE` 计算覆盖 block → `world/getBlockData`。
2. **加载**：解析块串（§3.3）→ 逐格贴地形（`type`→`WorldPanel_<terrain>`）；城池贴 `WorldPanel_city*`；`state=1` 战乱叠红蒙版；有主城池叠归属旗 `WorldPanel_flag_*`（`flag` 由 `getWorldCityInfo` 定 0~8）；等级角标 `WorldPanel_level_*`；领地/活动/联盟标记分别用自身绿色/橙色/红色边框（重写版印证 `复刻对照表.md:450`）。
3. **平移/缩放**：`controlPanel` 八向按钮/拖拽（`tipPanel` 内 Canvas 的 mouse 事件，`1643-1648`）→ 更新中心 → 越出已加载区再 `getBlockData`。
4. **点击**：命中格 → 构造 grid 对象 → 城池待 `getWorldCityInfo`、野地待 `getWorldFieldInfo` 回包 → `actionDialog.setGridInfo`（§3.5）→ 显示对应按钮页。
5. **操作**：按钮 → §3.6/3.8 命令 → 后端；成功多经 `Exception` 文案返回（前端 `alert`）。
6. **错误分支**：政令 `onGovern` 前置 `Alert`（`World_WorldActionDialogSrc_22`「你所在城…」/`23`「名城官府…」/`24~26` 同县郡州校验）；`showCampaignDialog` 无兵营 `Alert`（`21`）；`GovernPanel.setGovernInfo`（`392-411`）按 `maxCount=0`（官职不足）/次数用尽分别 `Alert`（`24`/`26-29`）。
