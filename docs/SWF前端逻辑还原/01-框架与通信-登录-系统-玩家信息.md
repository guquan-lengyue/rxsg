## 4. 状态机与流程

### 4.1 启动 → 登录 → 主城（完整链）
```
SWF 载入 → Preloader/BloodWarDownloadProgressBar(加载进度, 随机提示) → INIT_COMPLETE

 → LoginDialog.onCreate: initLoginService + getLoginAnnouncement
     ├─ is51User → doLogin("51user","51user")
     ├─ passType=xiaonei/renren → checkXiaoneiUserAuth
     ├─ getWangye173Auth 非空 → checkUserAuth
     └─ 否则 showFlashLogin(显示表单)

 → Login::doLogin → onLogin 回包
     ├─ code=0  → Alert(ret[1]) + showLogin
     ├─ code=1,sub=1 → showQueue(人数) + 30s 轮询 checkQueue

     ├─ code=-100/-200 → 跳 51/xiaonei

     ├─ 不需加密 或 swfPassValue 已就绪 → loginGameNow
     └─ 需加密且未就绪 → onMyLoadSWF 加载验证码 → onSwfPassLoaded 后 loginGameNow

     + battle/getBattleNetUrl + battle/getUserBattleInfo

     ├─ 3 → CreateRoleDialog.setFirstTime(true) → 选省 → createRole → JackarooDialog
     ├─ 4 → CreateRoleDialog.setUserData → 选省 → createCity
     ├─ 5 → loginDialog.visible
```

### 4.2 休假状态机
正常(0)／&nbsp;申请休假 → `changeUserState [state,days]` → 服务端锁定 → `ustate=6`+`locked=true`+`VacationDialog`；登录时 vacend>now 同样进入锁定；取消：`serverTime-start<2天` 拒绝，否则 `changeUserState [0,"2"]`。

### 4.3 弹窗通用状态机（ServerDataHandler）
`sendDialogCommand`(dialog 通道) → 回包 `onDialogCommand`(校验 `City.cid`==cid) → `childOnCommand` 递归 → 命中可见 `ServerDataHandler.isTarget(receiverID,receiverParam)` 的弹窗 → `onData`。弹窗按 `ttype`(第 5 参) 区分同弹窗不同子页（如 `ID_BUILDING_HOTEL` ttype 3/4/8）。

### 4.4 敏感操作二次密码闭环
操作(拆城/解散将/解散兵/分解装/出售装/联盟换装) → `OpenLock.setFirstParam(type)` 展示提示 → `doCheck` → `openlock/openLock` → 服务端校验 → `onGlobalCommand "openlock"`：`isFirstSet`→设新密码提示；`isCorrect==false`→`OpenLock_title_password_wrong`；成功→执行对应 `dialogManager.*` 操作。

## 8. 原版怪癖与注意事项

1. **`getEncryptProtocol` 读取键错误**：`onGetConfigInfo` 判断 `getEncryptProtocol` 键存在，却用 `getValueByName(_loc4_,"getRegisterUrl")=="false"` 求值赋给 `Global.encryptProtocol`（`BloodWar.as:7974-7977`）——原版 bug，逐字保留。
2. **签名仅在正规域名生成**：`Command.getSign` 先判 `UrlUtils.isValidInternetHttpUrl(loaderInfo.url)`，否则返回空串（`Command.as:211-213`）；`UrlUtils` 的**黑名单**含 `.html/mywgame.com/58.215.65.114/jws.seafe.com/vostro.com.cn/222.76.214.21`（`UrlUtils.as:36`）；验证码 `BaseSprite.ab` 黑名单另含 `sg10.uuyx.com`（`pass/1.swf/scripts/BaseSprite.as:28`）。均为反调试/反私服手段。
3. **加密命令延迟队列**：`initCrypto` 未就绪时命令入 `delayedCommands` 排队，密钥到位后重放（`Command.as:78-124`, `159/265`）。
4. **`swfPass` 默认值 "WAIGUASB"**（`Global.as:38`）；真实密钥来自验证码 SWF 的 `passValue`（`BloodWar.onSwfPassLoaded:6364`），100 个验证码各自 `getKey()` 返回 `"99x<n>u"` 形式、密文不同（`pass/N.swf/scripts/swfpass.as`）。
5. **`BloodWar.alert` 分流**：文案含任意数字则用 `mx.controls.Alert`，否则用自绘 `AlertPanel`（`BloodWar.as:4918-4944`）。
6. **`AllowPK` 与 UserRule**：仅关闭用户守则时发送 `user/allowPK`（`UserRule.as:310`），非"是否允许 PK"开关。
7. **`SystemMenuPanel` 成年状态切换不回传服务端**：`changeAdultState/onChangeAdultState` 只调 `onCommand("adult",!mAdultState)` 更新本地绑定，未见 `sendGlobalCommand`（`SystemMenuPanel.as:465-491`）——**待确认**是否遗漏服务端同步。
8. **`GRID_DISTANCE` 客户端≠服务端**：`Define.as:8`=60000；服务端 `common.php:30`=6000（[复刻对照表.md:417](../复刻对照表.md) 已注明"以代码为准"）——客户端此值可能仅用于地图显示，**待确认**。
9. **多处命令不在 `openfunc` 白名单**：`loadMianZhanEndTime/changeUserDesignation/allowPK/useLiJianFu/openLock/modifyPassword/checkFcmOnline/sendCloseMsg` 等经 `sendGlobalCommand` 会被后端抛 `command_exception`（`lang.php:2669-2671`）——原版可能通过其它未导出路径放行，**待确认**（前端确有调用）。
10. **邮件/系统信渲染区分**：`readSysMail` 用 `htmlMailContent.htmlText`（支持 HTML），普通信/发件信走 `mailContent.text`（`MailDetailDialog.as:905-922`）。
11. **`not_enough_goods<gid>#<count>` 解析**：客户端拆分 `#`，缺道具时弹 `BuyAndUseGoodsDialog` 并发 `buyanduse/showDlg`（`Command.as:378-399`）。
12. **`switchCity` 双请求**：切换城池同时发 `getUserCities` + `getCityInfo(cid)` 并关闭所有弹窗（`BloodWar.as:6109-6114`）。
13. **心跳本地预测**：`InfoPanel.onTimer` 在客户端按 `/3600` 递增资源显示（`InfoPanel.as:2088-2099`），真实结算在服务端，存在显示漂移。
14. **Preloader 5 段进度文案**：按 `bytes*5/loading_width` 切换 `Preloader_BloodWarDownloadProgressBar_5..9`，`_3` 为百分号后缀（`BloodWarDownloadProgressBar.as:106-127`）。
15. **验证码 SWF 尺寸固定 500×375**（`[SWF(width="500",height="375"…)]`，`pass/N.swf/scripts/swfpass.as:3`），实际由 `uiComponent` 承载。
