# 热血三国：前后端分离重写 — 首期（Go/Gin REST 后端 + Vue3 前端，登录→进城主线）

## Context（背景与目标）

遗留中文网页游戏（热血三国类），需要前后端分离重写，最终去 Flash。

**现状（已核实）**

- **前端**：整站游戏界面为编译后的 Flash（`BloodWar.swf` 4.3MB，无 AS 源码），经 **AMF** 与后端通信。外围 JS：`BloodWar.html`（登录页）、`bloodwar.js`（`getEndPoint()` 指向 `/server/amfphp/gateway.php`）、`pass.js`、`lang_zh_CN.js`。
- **后端**：PHP，约 652 个文件 / 3.8MB（不含 vendor/amfphp）。
  - `server/amfphp/gateway.php`：AMF 网关。
  - `server/game/`：核心。AMF 服务类 `Login`、`Command`；`Command::sendCommand()`（`server/game/Command.php:49`）是命名式分发器，用 `function_exists()` 调用 ~100 个 `*Func.php` 的自由函数。
  - `manage/`（433 文件，运营后台）、`BandServer/`（军团/贸易）、`server/game/passport/`（多平台登录）、`cronServer/`、`user/`。
- **数据库**：MySQL 库 `bloodwar`（`server/config/db.php`）。代码引用 **390 张表**（`sys_*/mem_*/cfg_*/log_*`），**仓库内无 `.sql`**。
- **访问层** `server/lib/mysql.php`：`prepare()` 走 PDO，但 SQL 全字符串拼接、无参数绑定。

**首期范围（已确认）**

1. 交付**可运行骨架 + 一条垂直切片**：登录 → 进入城市 → 拉取城市信息。
2. 后端 **Go + Gin**，前端 **Vue3**，**干净 REST API**（不沿用 legacy 的命名式 RPC；但复用其 DB schema 与业务读取逻辑）。
3. Flash 战斗/地图后续用 Canvas/WebGL 逐步重写，本期不做。
4. 复用现有 MySQL schema；新增 `backend/` 与 `frontend/`，legacy 原样保留对照。

## 一、目标架构

```
Vue3 SPA (Vite)  ──HTTP/JSON──▶  Go + Gin REST API  ──database/sql+s sqlx──▶  MySQL bloodwar（复用）
   Canvas 渲染层                     JWT 会话 + 中间件                        现有 390 张表
```

- 认证：**JWT(HS256)**，claims `{uid, sid}`；同时把 `(uid, sid, ip)` 写入 `sys_sessions` 以便失效与 legacy 互操作；`sid` 仍由服务端 `rand()` 生成（兼容既有列类型）。
- 协议：资源型 REST + HTTP 状态码；成功直接返回资源 JSON；错误统一 `{"code","message"}`，`code` 复用 legacy 消息键（`invalid_user_auth`/`not_user_city`/`server_is_updating`…）以便前端 i18n。
- SQL：新代码**全部参数化**（`?`），不再字符串拼接。

## 三、后端实现步骤（`backend/`）

### 步骤 1：工程骨架

- `backend/go.mod`，module `rxsg/backend`，Go 1.22。
- 依赖：`github.com/gin-gonic/gin`、`github.com/go-sql-driver/mysql`、`github.com/jmoiron/sqlx`、`github.com/golang-jwt/jwt/v5`、`github.com/spf13/viper`。
- `backend/config.yaml`：`server.port`、`db.{host,port,user,password,name,charset}`（值取自 `server/config/db.php`：`root/123456@127.0.0.1:3306/bloodwar,utf8`）、`jwt.{secret,ttl}`、`session.fileDir`（对齐 `ROOT_PATH/sessions`）。
- `backend/cmd/server/main.go`：加载配置 → 打开 DB → 建路由 → `Run`。
- **验证**：`go build ./...` 通过。

### 步骤 2：数据层 `internal/db`

`db.go`：`Open(cfg)` 建 `*sqlx.DB`（`parseTime=false`，`charset=utf8`，`SetMaxOpenConns/SetConnMaxLifetime`）。

同名 helper（语义对齐 `server/lib/mysql.php`）：

| Go | 语义 | 对齐 PHP |
|---|---|---|
| `FetchOne(ctx,q,args)` `(map[string]any, error)` | 单行或 `sql.ErrNoRows` | `sql_fetch_one` |
| `FetchRows(ctx,q,args)` `([]map[string]any,error)` | 多行 | `sql_fetch_rows` |
| `FetchOneCell[T]` / `FetchCellString/Int64` | 首行首列 | `sql_fetch_one_cell` |
| `Exec(ctx,q,args)` `(int64,error)` | 影响行数 | `sql_query` |
| `Insert(ctx,q,args)` `(int64,error)` | lastInsertId | `sql_insert` |
| `Exists(ctx,q,args)` `(bool,error)` | 是否有行 | `sql_check` |

对契约敏感的城市接口用 `sqlx` 的 `Select/Get` + 显式 struct（避免 map 丢列序）。

### 步骤 3：认证 `internal/auth`

- `service.go`：`Login(ctx, req)` 复刻 `Login::doLogin`（`Login.php:28-334`）关键路径：
  1. 校验 `select * from test_passport where passport=?`，**明文比较**密码（`myrxsg.php:10`）；`len(password)<4` → 400。
  2. 查 `sys_user`(passport+passtype)；不存在则建号：`insert into sys_user(passtype,passport,group,state,money,regtime,domainid,honour) values(?,?,0,3,88888,unix_timestamp(),0,1000)`（`Login.php:155`）。
  3. `sid = rand()`；`realLogin` 核心子集：`insert into sys_sessions(uid,sid,ip) values(?,?,?) on duplicate key update sid=?,ip=?`（`utils.php:397`）、写 `sessions/<uid>` 文件、`update sys_online ...`（`utils.php:403`）、`insert into log_login(...)`（`utils.php:412`）。
  4. 签发 JWT → 返回 `{token,expiresIn,user}`。
- `jwt.go`：`Sign(uid,sid)`、`Parse(token)`。
- **首期显式降级（记 TODO）**：`realLogin` 内的排行 `rank_user`、补礼包 `giveDalibao`、联盟 `updateUnionRank`、系统广播 `sendSysInform`、防沉迷 `updateFcmTime`、`cfg_baned_ip` 判定先做**最小实现或跳过**，避免引入 20+ 张非核心表；在代码中以 `TODO(phase2)` 标注。
- **验证**：用现有 `test_passport` 账号登录，`sys_sessions` 新增/更新，`sessions/<uid>` 生成。

### 步骤 4：中间件 `internal/middleware/auth.go`

`RequireAuth`：读 `Authorization: Bearer <token>` → `jwt.Parse` → 取 `uid,sid` → 校验 `select 1 from sys_sessions where uid=? and sid=?`（失效即 401 `invalid_user_auth`）→ 写入 Gin context。

### 步骤 5：城市域 `internal/city` + `internal/model`

复刻函数 → Go 方法对照：

| legacy | 位置 | Go |
|---|---|---|
| `checkCityOwner` | `utils.php:211` | `ensureOwner(ctx,cid,uid)` → 403 |
| `cid2wid` | `utils.php:663` | `cid2wid(cid) int` |
| `getSpacialSoldierId` | `utils.php:865` | `specialSoldierId(ctx,cid)` |
| `getCityBuildingInfo` | `utils.php:776` | `Buildings(ctx,cid)` |
| `doGetCityBaseInfo` | `utils.php:798` | `BaseInfo(ctx,uid,cid)` |
| `doGetCityAllInfo` | `utils.php:846` | `CityDetail(ctx,uid,cid)` |

涉及的 SELECT（显式列，参数化）主要表：`sys_user, sys_city, mem_city_resource, sys_city_hero, mem_hero_blood, sys_city_soldier, sys_city_defence, sys_building, cfg_building, cfg_building_level, sys_city_technic, mem_world, cfg_soldier_special_city, sys_alarm, mem_state, sys_activity`。

`internal/model` 按 `server/game/interface.php` 的 `City/Grid/BuildingState/TechnicState/ArmySoldierState/WallDefenceState` 定义 DTO（JSON tag 用 camelCase，前端 TS 对齐）。

- **注意资源累积**：`getCityInfo` 路径会触发 `SetCityBaseProduce`(`utils.php:2145`) 与 `UpdateUsersCityResource`(`utils.php:2329`) 写库。首期**只读**，不执行写库累积，仅返回当前值；写累积留到 phase2（以 `TODO(phase2)` 标注，避免误改资源）。
- `internal/lock/lock.go`：`WithUserLock(ctx,uid,key,fn)` 用 `GET_LOCK/RELEASE_LOCK`，替代 `userlock/*.lock`（`utils.php:1201`）。首期仅心跳/详情读取不涉及加锁，先提供基础设施。

### 步骤 6：路由与响应

- `internal/httpx/response.go`：`WriteError(c, err)` 统一 `{code,message}` + 状态码；`APIError{Code,Message,Status}`。
- `main.go` 注册第二节全部路由；`GET /api/health` 返回 `{status:"ok"}`。

### 步骤 7：数据库基线

- 有运行库：`mysqldump --no-data --skip-comments bloodwar > backend/migrations/0001_baseline.sql`。
- 无运行库：手写 `backend/migrations/0002_minimal.sql`，仅建跑通切片所需最小表：`test_passport, sys_user, sys_sessions, sys_online, sys_city, mem_city_resource, sys_city_hero, mem_hero_blood, sys_city_soldier, sys_city_defence, sys_building, cfg_building, cfg_building_level, sys_city_technic, mem_world, cfg_soldier_special_city, sys_alarm, mem_state, sys_activity, log_login`（列名从上述 SELECT/INSERT 反推）。

## 四、前端实现步骤（`frontend/`）

### 步骤 1：脚手架

Vite + Vue3 + TS + Pinia + Vue Router + axios（+ Element Plus 可选）。`vite.config.ts` 配 `server.proxy['/api'] → http://localhost:8080`。

### 步骤 2：基础设施

- `src/api/http.ts`：axios 实例 `baseURL=/api/v1`；请求拦截注入 `Authorization: Bearer <token>`；响应拦截 401 → 清 token 跳 `/login`。
- `src/types/*.ts`：镜像 Go DTO（`User/City/Building/Technic/CitySoldier/CityDefence/Hero/Province`）。
- `src/api/auth.ts`：`login/logout/me/announce`。
- `src/api/city.ts`：`listCities/getCity/getResources/getBuildings/getTechnics/getTroops/getDefences/getHeroes/getAlarms`。
- `src/stores/auth.ts`：`token/user` + `localStorage` 持久化 + `login()/logout()/restore()`。
- `src/stores/city.ts`：`currentCity/resources/buildings`；`startHeartbeat(cid)` 每 **10s** 轮询 `resources`（对齐 `getCityBaseInfo` 节奏），`stopHeartbeat()`。

### 步骤 3：页面

- `src/views/LoginView.vue`：对齐 `BloodWar.html` 登录表单（账号/密码/记住我 + 公告），成功后跳 `/city`。
- `src/views/CityView.vue`：`ResourceBar` + `BuildingGrid` + 城池名/坐标；进入时 `getCity`，再 `startHeartbeat`。
- `src/components/ResourceBar.vue`：粮食/木材/石料/铁锭/黄金/人口/民心。
- `src/components/BuildingGrid.vue`：调用渲染层。
- `src/render/cityGrid.ts`：原生 **Canvas 2D** 绘制城内网格；按 `sys_building.x/y/bid/level/state` 画建筑与等级、升级中倒计时（`stateTimeLeft`）；PixiJS 预留给后续大地图/战斗。
- `src/router/index.ts`：`/login`、`/city/:cid?`；守卫无 token → `/login`。
- `src/lang/zh-CN.ts`：先抽用 `lang_zh_CN.js` 文案。

## 六、验证（端到端）

1. **构建**：`cd backend && go build ./...`；`cd frontend && npm i && npm run build`。
2. **健康检查**：`go run ./cmd/server` 后 `curl localhost:8080/api/health` → `{"status":"ok"}`。
3. **登录**：`curl -X POST /api/v1/auth/login -d '{"passport":"<现有账号>","password":"<密码>"}'` → 200 且返回 `token`；查 `sys_sessions` 有对应 `(uid,sid)`、`sessions/<uid>` 文件存在。
4. **契约对齐**：同 `uid/cid` 分别跑 **legacy PHP**（`getCityInfo`）与 **Go**（`GET /cities/{cid}`），转 JSON 做字段 diff，确保一致（首期允许"资源累积写库"这一处差异）。
5. **前端联调**：`npm run dev`，用 `browser_use` 子代理打开登录页 → 登录 → 进城市 → 断言资源条数值、建筑网格渲染、10s 心跳无 4xx/5xx。
6. **无回归**：`git status` 确认 legacy 目录未被改动。

## 七、风险与未决

- **无 `.sql` schema**：必须反向导出；手写最小集存在字段偏差风险（以步骤 4 的 diff 兜底）。
- **`realLogin` 依赖面广**（`rank_user/cfg_baned_ip/sys_mail_sys_box/...`）：首期降级实现，明确 `TODO(phase2)`。
- **资源累积语义**：首期只读不写，与 legacy 有已知差异，需在 phase2 补齐 `SetCityBaseProduce/UpdateUsersCityResource`。
- **`$GLOBALS['openfunc']` 白名单**（`Command.php:77/114`）在 REST 化后不再需要，但对应"可执行操作"的权限需在后续写接口时重新设计。
- **文件锁 → DB 锁**语义需压测确认。
- 本期**不迁移**：`manage/` 后台、`BandServer/`、`cronServer/`、充值/平台支付（`pay/passport`）、战斗网络（`BattleNet*/Chibi*`）。
